# Roadmap

> Milestones are ordered by dependency, not by date. M0 to M2 are done; the rest is the plan. Each milestone from M1 on ends with a tagged prerelease built for every platform by the release workflow. Command ids refer to [COMMANDS-PLAN.md](COMMANDS-PLAN.md).

## M0 — Planning (this repository)

- [x] README, feature survey ([INNOVATIONS.md](INNOVATIONS.md)), command inventory ([COMMANDS-PLAN.md](COMMANDS-PLAN.md), generated from [commands-plan.src.txt](commands-plan.src.txt)), classic menu layouts ([MENUS-PLAN.md](MENUS-PLAN.md)), Quick Access Bar plan ([QAT.md](QAT.md)), AI plan ([AI-PLAN.md](AI-PLAN.md)), formats ([FORMATS-PLAN.md](FORMATS-PLAN.md)), recovery ([RECOVERY-PLAN.md](RECOVERY-PLAN.md)), architecture ([ARCHITECTURE-PLAN.md](ARCHITECTURE-PLAN.md)), legal notes, license, contributing guide and issue templates.
- [x] `scripts/gen-plan.py` validates ids, menu references, origins and shortcut conflicts.
- [x] Verify the classic menu arrangements and default keys against IrfanView 4.x, XnView MP, FastStone, ACDSee, Picasa 3, Windows Photo Viewer/Photos, Preview and digiKam, and correct [menus-plan.src.txt](menus-plan.src.txt). Done against the programs' published documentation and their own menu resources (installed copies were not available; see DECISIONS.md): IrfanView's menu file and hotkey page, XnView MP's menu bars and defaults, FastStone 8.5's menu definitions and help, ACDSee's help, Picasa 3.9's string tables and Google's shortcut list, Apple's Preview guide, the digiKam manual; Microsoft's Photo Viewer documentation no longer exists, so that layout stays as planned. Seven layouts were rearranged and nine default keys corrected.
- [x] Collect an openly licensed test corpus: every format in FORMATS-PLAN.md, camera RAW samples with redistribution rights, multipage and animated files, damaged files. [CORPUS.md](CORPUS.md) lists the fixtures per format with their provenance and licenses; `scripts/fetch-corpus.py` downloads the CC0 RAW samples of raw.pixls.us (one per format) and NASA's public-domain FITS samples, makes damaged copies, and `tests/unit/corpus.test.ts` runs over them (which found and fixed a gap: TIFF-based RAW files without a JPEG preview now show their uncompressed thumbnail).
- [x] Confirm the license of every on-device model the app downloads (MODNet, Depth Anything V2 Small, LaMa and Swin2SR are Apache-2.0, CLIP ViT-B/32 is MIT; checked on the model cards). The other candidates in AI-PLAN.md are confirmed when they are added.
